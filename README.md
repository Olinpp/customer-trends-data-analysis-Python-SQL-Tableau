# 📊 Customer Behavior Analysis & Dashboard

Proyek ini bertujuan untuk menganalisis tren dan perilaku pelanggan (*customer behavior*) menggunakan teknik analisis data serta menyajikannya dalam bentuk dashboard interaktif. 

---

## 🚀 Live Dashboard
Lihat visualisasi data dan dashboard interaktif secara langsung melalui tautan berikut:
* 📊 **Tableau Interactive Dashboard:** [Customer Behavior Dashboard](https://public.tableau.com/views/CustomerBehaviorDashboard_17854760641890/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

---

## 📌 Deskripsi Proyek
Proyek ini mencakup eksplorasi data, pemrosesan data, serta visualisasi untuk memahami pola pembelian dan demografi pelanggan. Dengan adanya visualisasi ini, diharapkan dapat memberikan wawasan terukur untuk mendukung pengambilan keputusan berbasis data (*data-driven decision making*).
